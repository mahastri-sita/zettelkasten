# AGENTS.md

## Scope

These rules apply to `argument/` and all descendants. Inherit the root `AGENTS.md`.

This branch contains personal intellectual work. It is not an AI-maintained summary layer. Preserve the distinction among thinking in motion, mature synthesis, and confirmed intellectual history.

## Shared Rules

- The user is the intellectual owner of claims, frameworks, interpretations, and positions in this branch.
- AI may investigate, critique, identify assumptions, find counterevidence, test consistency, and propose changes.
- Do not silently replace the user's framing, causal account, normative position, or interpretation.
- Do not present an AI-generated source digest as the user's argument.
- Keep important claims traceable to Source or Calculation objects.
- Make counterevidence and uncertainty visible instead of smoothing them into false consensus.
- Do not create files in this branch without the authority specified by the root and leaf instructions.

## Flow Boundaries

Valid flows include:

```text
source / calculation -> argument -> synthesis-product
argument -> output -> candidate synthesis-product
```

An invalid flow is:

```text
source -> synthesis-product
```

Source material must pass through the user's argumentation before it can become personal synthesis.

## Fragmentation

Do not split intellectual work because of length. Propose or perform a split only when a component has independent meaning and reuse value outside the current note. If the split changes the structure of personal work, obtain explicit editing intent first.

# AGENTS.md

## Scope

These rules apply to `source/journal/`. Inherit `source/AGENTS.md` and the root `AGENTS.md`.

Use this folder for journal articles and journal reviews. Do not assume peer-review status unless it can be verified.

## Naming

Use `Author - Year - Short Title.md`. For many authors, use the first author followed by `et al`. If authorship is unavailable, use the responsible institution or journal.

## Type-Specific YAML

Add these fields to the required Source core:

```yaml
journal: null
volume: null
issue: null
pages: null
doi: null
```

## Processing

- Capture the research question, theoretical position, unit of analysis, geography, period, method, principal findings, and stated limitations when available.
- Attach page, table, or figure locators to load-bearing claims.
- Distinguish results reported by the authors from the authors' interpretation and from the processing agent's inference.
- For review articles, identify the review method and corpus limits rather than treating the article as direct empirical evidence.

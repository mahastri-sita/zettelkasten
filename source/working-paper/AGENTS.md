# AGENTS.md

## Scope

These rules apply to `source/working-paper/`. Inherit `source/AGENTS.md` and the root `AGENTS.md`.

Use this folder for working papers, discussion papers, preprints, and research manuscripts not verified as final journal publications.

## Naming

Use `Author - Year - Short Title.md`. Add a version or series number only when needed to distinguish releases.

## Type-Specific YAML

Add these fields to the required Source core:

```yaml
institution_or_series: null
paper_number: null
version: null
doi: null
```

## Processing

- Record the version or release date when available.
- Do not describe the paper as peer-reviewed unless that status is verified.
- Check whether a later published version exists when that question matters to the task.
- Preserve method, evidence, findings, scope, and limitations as reported in the accessed version.
- Do not silently replace the accessed version's claims with those of a later version.

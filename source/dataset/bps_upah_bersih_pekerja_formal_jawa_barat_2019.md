# Upah Bersih Pekerja Formal Jawa Barat 2019

## Dataset Description

Tabel BPS/Sakernas tentang rata-rata upah/gaji bersih bulanan pekerja formal menurut kabupaten/kota dan lapangan pekerjaan utama di Jawa Barat pada 2019.

## Variables or Schema

- Header tersusun dalam beberapa baris.
- Kategori lapangan pekerjaan utama ditandai 1, 2, dan 3; catatan CSV menjelaskan pengelompokan tersebut.
- Tersedia kolom jumlah total serta baris kabupaten, kota, dan Jawa Barat.
- Nilai `NA` dipertahankan sebagaimana raw file; makna missing value tidak ditafsirkan.

## Coverage and Unit of Observation

Cakupan geografis adalah kabupaten/kota di Provinsi Jawa Barat. Unit observasi mengikuti baris wilayah dan kategori lapangan pekerjaan pada tabel sumber.

## Collection or Production Method

Baris sumber pada CSV menyebut BPS dan Survei Angkatan Kerja Nasional (Sakernas) Agustus. Metode ekstraksi file dan metadata rilis tidak tercatat.

## Known Limitations

- URL, tanggal unduh, dan metadata rilis tidak tersedia.
- Struktur header multi-baris belum dinormalisasi.
- Tidak ada transformasi atau validasi angka yang dilakukan.

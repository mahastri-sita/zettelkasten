# Upah Bersih Pekerja Formal DKI Jakarta 2019

## Dataset Description

Tabel BPS/Sakernas tentang rata-rata upah/gaji bersih bulanan pekerja formal menurut kabupaten/kota dan lapangan pekerjaan utama di Provinsi DKI Jakarta pada 2019.

## Variables or Schema

Kolom yang tersedia mencakup wilayah, pertanian, industri, jasa, dan jumlah. Header sumber tersusun dalam beberapa baris; tanda `-` dipertahankan dan tidak ditafsirkan sebagai jenis missing value tertentu.

## Coverage and Unit of Observation

Cakupan geografis adalah kabupaten/kota di Provinsi DKI Jakarta serta baris agregat DKI Jakarta. Unit observasi mengikuti baris wilayah dan kategori pekerjaan pada tabel sumber.

Pengguna mengonfirmasi bahwa tabel ini berasal dari BPS/Sakernas. Metode ekstraksi dan metadata rilis tidak tercatat di dalam CSV.

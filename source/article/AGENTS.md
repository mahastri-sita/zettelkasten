# AGENTS.md

## Scope

These rules apply to `source/article/`. Inherit `source/AGENTS.md` and the root `AGENTS.md`.

Use this folder for news reports, magazine pieces, web articles, essays, and other non-journal articles.

## Naming

Use `Author - Year - Short Title.md`. If no author is identified, use `Publication - Year - Short Title.md`.

## Type-Specific YAML

Add these fields to the required Source core:

```yaml
publication: null
publication_date: null
archived_url: null
```

## Processing

- Distinguish firsthand reporting, quoted third-party statements, editorial interpretation, and opinion.
- Record the publication date and access date because web content can change.
- Preserve an archived URL when available and useful.
- Do not treat journalistic or opinion claims as equivalent to peer-reviewed or primary empirical evidence without corroboration.

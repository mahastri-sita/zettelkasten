# AGENTS.md

## Scope

These rules apply to `topic-notes/level-1/`. Inherit `topic-notes/AGENTS.md` and the root `AGENTS.md`.

Level-1 notes represent broad, relatively stable fields or disciplinary areas, such as `Urban Morphology`, `Housing`, `Regional Economics`, or `Urban Transportation`.

## Creation and Content

- Create Level-1 notes sparingly.
- Use a canonical field name as the filename.
- Keep scope broad enough to organize multiple Level-2 topics and knowledge objects.
- Link relevant Level-2 topics with a short explanation of how each sits within or crosses the field.
- Link another Level-1 field when the cross-field relationship improves navigation.
- Do not force each Level-2 note to have only one Level-1 parent.
- Do not turn a Level-1 note into a textbook overview or exhaustive catalog.
